## What I Focus On

### AI Infrastructure

I focus on how Kubernetes platforms allocate GPUs, schedule training jobs, and deploy models for online inference. I'm particularly interested in recovering failed training jobs without losing completed work and keeping inference latency predictable as traffic changes.

### Kubernetes and Progressive Delivery

I'm interested in the control planes that manage application releases across clusters. I pay attention to how they reconcile workload state, show deployment progress, and use health signals to advance, pause, or roll back a release.

### Observability and Incident Response

I focus on connecting alerts with telemetry and recent changes so on-call engineers can narrow down what failed. I'm also interested in how automated diagnostics can gather evidence that engineers can review during an incident.

### Agent Runtimes and Sandboxes

I'm interested in how agents run tools and code in isolated environments. That includes provisioning, resource limits, and cleanup, as well as how runtime APIs give callers a consistent way to manage those environments.
